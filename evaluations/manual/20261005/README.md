# 手動受入の保存記録

テスト用Gitリポジトリ、分離したSQLiteデータベース、ポート4330で確認した記録です。利用者の製品データを使っていません。

- `first-build-identity.json`: 最初の確認に用いたビルドのハッシュ。
- `first-run-result.json`: Qwen3.5-4Bの応答が契約に適合しなかった実行。成功には数えません。
- `resumed-run-result.json`: コード行付き候補を返した実行を再開し、保存済みのモデル工程1件を再利用した記録。全体は未診断範囲を残す `partial` です。
- `knowledge-lifecycle-final.json`: 画面から資料を改版した後、旧版を参照する承認済み知識が失効した状態。

これらは接続、保存・再開、知識の失効の確認です。見逃し・誤検知の削減、未知の脆弱性の発見、人の所要時間、Logosに対する優位性の証拠にはしません。詳細は[検証記録](../../../docs/testing/2026-10-05-model-review.md)を参照してください。
